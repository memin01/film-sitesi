# film-sitesi
Bu proje, HTML, CSS ve JavaScript kullanılarak geliştirilmiş, kullanıcı dostu ve görsel açıdan zengin bir film tanıtım platformudur. Amacım; sade ama etkileyici bir arayüzle film içeriklerini sunmak, aynı zamanda responsive tasarım, etkileşimli bileşenler ve görsel tutarlılık gibi temel kullanıcı deneyimi prensiplerini uygulamaktı.
